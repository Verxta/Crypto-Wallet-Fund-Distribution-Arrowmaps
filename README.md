# Crypto-Wallet-Fund-Distribution-Arrowmaps
Track wallets by sourcing funded wallet addresses. Finding and labeling wallets based on fund sourcing.


Crypto-Wallet-Fund-Distribution-Arrowmaps (https://github.com/Verxta/Crypto-Wallet-Fund-Distribution-Arrowmaps) is inspired by MetaSleuth, Simulink dynamical information flow, and blockchain transaction histories.

To run:

All files needed to be downloaded.
Navigate to /[Your Directory Path]/GitHub/Crypto-Wallet-Fund-Distribution-Arrowmaps/walletflow/Start WalletFlow.command This runs a bash command script that runs the application as a local web application with API calling to the internet in order to acquire information and fund histories.
